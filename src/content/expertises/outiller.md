Nous développons des outils de collecte de données de terrain mobiles, des applications web pour l'analyse de la trésorerie des exploitations agricoles, des interfaces de cartographie numérique. Ces outils sont parfois nécessaires pour diverses études, pour la gestion de certains projets ou encore pour le suivi-évaluation.

**Stack** : React / React Native, Node.js, PostgreSQL/PostGIS, GeoServer, QGIS, KoboToolbox / Qfield, Firebase, Electron.

**Outils développés** : Agroscopik, Endagri (analyse de trésorerie tunisienne), Agroécoloscore (GTAE), plateforme cartographique de l'Alliance pour la Préservation des Forêts, Atlas Numérique des Agricultures du Monde.
